# 新人類 - 六道輪迴

![新人類遊戲界面](https://via.placeholder.com/800x400/1a1a2e/4ecdc4?text=新人類+六道輪迴)

一個基於Web的鏈遊概念驗證，融合了DNA系統、六道輪迴、優先級戰鬥等創新機制。

## 🎮 遊戲特色

### 🔮 DNA系統
- **隱性標籤**：記錄玩家的經歷和選擇
- **觸發條件**：特定DNA會在特定情境下觸發特殊效果
- **戰鬥加成**：DNA標籤提供戰鬥屬性加成
- **世界關聯**：不同世界的DNA相互影響

### 🌌 六道輪迴
- **靈魂體移動**：白貓式單指滑動操作
- **世界探索**：多個相互關聯的世界線
- **永久後果**：死亡導致帳號重置，重新開始輪迴
- **種子系統**：六道種子開啟輪迴之旅

### ⚔️ 優先級戰鬥
- **行動點系統**：基於速度和偷襲的行動點計算
- **多動作連擊**：高行動點可連續執行多個動作
- **DNA技能**：特殊DNA解鎖獨特戰鬥技能
- **實時切換**：行動點多的一方繼續行動

### 🎨 美術風格
- **沙粒藝術**：AI生成的沙粒藝術風格
- **文字敘事**：豐富的文字描述和故事線
- **流暢動畫**：CSS3 + JavaScript平滑過渡

## 🚀 開始遊戲

1. 訪問遊戲頁面：[offline_game.html](./offline_game.html)
2. 用手指拖動靈魂體進行移動
3. 點擊底部按鈕探索不同功能
4. 種植六道種子開始你的輪迴之旅

## 📱 操作指南

### 移動控制
- **手指滑動**：拖動靈魂體到任意位置
- **慣性效果**：快速滑動會有輕微慣性

### 六道輪迴界面
- **🌱 種子**：種植六道種子開啟輪迴
- **📦 倉庫**：查看NFT裝備和DNA標籤
- **⚔️ 戰鬥**：測試優先級戰鬥系統
- **🌍 世界**：選擇進入不同世界線

### 戰鬥系統
- **攻擊**：基礎攻擊，消耗5行動點
- **防禦**：提升防禦力，消耗3行動點  
- **DNA技能**：使用特殊DNA技能，消耗8行動點
- **物品**：使用攜帶物品，消耗2行動點

## 🛠️ 技術架構

### 前端技術
- **HTML5/CSS3**：響應式設計，移動端優先
- **JavaScript**：模塊化架構，易於擴展
- **本地存儲**：localStorage保存遊戲進度

### 核心模塊
- `soul_movement.js` - 白貓式移動系統
- `dna_system.js` - DNA標籤管理系統  
- `combat_system.js` - 優先級戰鬥系統
- `six_paths_ui.js` - 六道輪迴用戶界面
